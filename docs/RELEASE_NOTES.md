# MGO2WIN / MGO2HOST v0.01-20260914031351

2026年9月14日版。9月13日からの更新をまとめた、Windows向け実験版の**フルセット**です。クライアント、専用HOST、実行用データを含み、以前の配布物は必要ありません。両方をこの同じバージョンで使用してください。

## 主な更新

- 4マップ（map 1 / 4 / 20 / 21）の通常DM・TDM、HOST管理の出撃・死亡・再出撃、時間切れ後の次ラウンド準備を統合しました。
- AK102の射撃・装填・設置／ドロップ／回収、材質による弾の貫通と減衰、弾痕、既知の材質音・足音、発砲ライトを追加しました。水域の移動・波紋・飛沫も一部に対応します。
- 他プレイヤーの外見・姿勢、敵の名前と取得済みクラン画像、TDMのSOPリンクを表示します。SOPは壁越しのオレンジ色の人形と走査演出を備え、男性の敬礼動作に対応します。
- チャット、定型無線の選択・受信表示・対応音声、BGMのループと場面切替、ブリーフィングの地図・ルール表示を改善しました。
- カメラの通常／肩越し／主観設定、入力割当、スキル設定と対応サーバー経由の戦闘補正、日本語16文字のプレイヤー名に対応する拡張を統合しました。
- 日本語の招待通知が画面上端を流れます。STARTメニューから返答画面を開き、承諾／辞退できます。到着時に戦闘を遮るダイアログは開きません。通信の無通信時間対策と失敗時の診断も改善しました。

## 現在の制限

- 完成版ではなく、通常DM・TDM、DP無効、AK102、単一マップの反復を中心とする限定実装です。全武器・投擲・全ルール・全動的背景物の再現は未完成です。
- 部位判定は男性の立ち／しゃがみ／伏せの静止姿勢による近似です。女性や全アニメーションへの追随は未完了。頭・首は現在1倍で、特殊なヘッドショット処理は未接続です。
- SOPの人形・走査、一部の水・ライト・物理表現はWindows版の試作です。女性のゲーム中敬礼、原版と同じ残響・遮音処理などは未完成です。
- 拡張名・スキル保存／補正・クラン画像は接続先サーバーの対応が必要です。サーバー未対応時に取得・保存・補正が成功したとは表示しません。
- 現在の対応バックエンドで招待を生成できるのはSurvivalです。Tournamentの生成と、承諾後の登録ロビーへの自動移動は未実装です。
- 実LAN・別PC間の長時間接続、実パッド対戦、実際の招待操作は未検証です。以前報告された入室後のタイムアウトについて、対策後の実機確認が残っています。

Release全体で177試験が成功し、その後の招待入力ガード修正では関連6試験が成功しました。これはローカル試験の結果で、実機対戦の完了を示すものではありません。
