# MGO2WIN — お試し版

[English](README.md) · [ダウンロード](https://github.com/Master-Mkt/MGO2WIN/releases)

OpenMGO2向けネイティブWindowsクライアントの実験版です。Direct3D 11と変換済みゲームリソースを使用します。タイトル・アカウント・キャラクター・ロビー・ルーム画面の試作で、対戦はまだできません。

## ソース更新 — 2026-09-12

ロビー選択を左のゲーム種別・右のロビー名と人数の2列に変更しました。左右／Tabで列、上下で項目、Enterまたは右端の矢印クリックで入場します。設定はフォルダー形タブになり、メニュー行の濃淡と選択位置のオレンジのクロスを追加しました。元の背景アニメーションと音楽を引き続き使います。今回はソースと文書のみの更新です。ダウンロードできる `v0.1.0-preview.1` のEXEはこれらの変更より前の版で、Release ZIPは差し替えていません。

## 起動方法

ReleasesからWindows x64版ZIPをダウンロードし、フォルダー全体を展開して `MGO2WIN.exe` を起動してください。`data` はEXEの隣に置きます。Windows 10/11 x64とD3D11対応環境が必要です。実行時にPython・IDA・Noesis・エミュレーターは不要です。

Enterで開始し、OpenMGO2から取得した同意文でYESを選び、自分のゲーム用アカウントを入力してください。接続先はOpenMGO2です。この版は1回の起動が10分に制限されています。終了後は再起動できます。EXEは未署名です。ログと任意の保存設定は `%LOCALAPPDATA%/MGO2WIN` に置かれます。

- 変換済みの元背景アニメーション、タイトル・ロビーBGM、START音・操作音。

- ポート設定・STUN診断、256〜2048 kbps設定、キーボード／XInputのキー割当、画質設定。
- アカウントのキャラクター一覧、元モデル・テクスチャの組合せとロビーモーション。228モデル項目・1,314画像。
- PC作成画面、Unicode名、性別、装備、男女8種類ずつの音声、ピッチ−7〜＋7。内容確認のYESで実際の登録要求を送信します。
- 服のテクスチャ復旧、ゴーグルなどmode2材質のRGB色対応。名前は最低4文字相当、最大16 UTF-8バイトです。

- 6分類のロビー、ルーム一覧・詳細、パスワード入力、ホスト接続。中止・時間切れ・拒否時の処理。
- 最大24枠のホスト参加者一覧、入退室による更新、ホスト／自分の表示。
- ホストが選択したマップ・ルール番号、ローテーション位置とラウンド／マップ変更を確認できるステージ情報画面。
- 元画面を参考にした、角を斜めに落とした半透明オレンジの選択表示と共通見出し。

## 未実装・制限

以前のローカル版で実アカウントのPC選択、フリーバトルのロビー入場、ユーザーが建てた既存ルームへの参加・退室を確認しています。最新の参加者更新とステージ情報は、オフライン画面試験と元の通信記録の再生で検査済みですが、実ルームでの確認はまだです。現在のソースはn022aの形状・テクスチャ・半球照明の近似・当たり判定・参考配置を読み込みます。ただし、全物体の受信完了、元actorの完全な起動、移動・対戦、参加者間通信、ホスト移行は未完成です。

PC削除の通信、PCスロット購入・決済は未実装で、削除確認は画面のみです。4キャラ無料はクライアント側の仕様で、対応するサーバー側の上限制御も配備済みです。PC作成は模擬応答で検査しており、配布EXEでの実登録成功は未確認です。登録結果が不明なときは、再送する前に一覧を確認してください。日本語名16文字はクライアント・サーバー双方を変更する将来対応で、現行の最大16 UTF-8バイトは変更していません。

17モデル項目、mode3材質、元の反射・透過、装備固有モーション、PS3との厳密な画質一致は未対応です。影バッファサイズ・通信速度は設定保存までで、対戦への反映は今後の工程です。動画再生も保留中です。

## ソースとリソース

Gitにはネイティブのソースと出典表記を置き、ReleaseのZIPには変換済み実行リソースも同梱します。元アーカイブ・ELF/SELF・元GCX/MDN/MTAR/TXN・IDAデータベース・SDK・認証情報・個人設定は含めません。タイトルの進行はオフラインで `data/title.gwp` へ変換し、お試し版は元GCXを読まずに動きます。通常タイトル経路に限定した処理で、GCX全体の実装ではありません。

ゲーム由来リソースの権利は元の権利者に帰属し、形式変換によって新しいライセンスを与えるものではありません。プロジェクト全体のオープンソースライセンスは未選定です。[ライセンス状況](LICENSE_STATUS.md)と[出典・第三者表記](THIRD_PARTY_NOTICES.md)を参照してください。Konami公式製品ではありません。

## ビルド

Visual Studio C++ Build Tools、Windows SDK、CMake 3.24以上を用意し、`cmake -S . -B build -A x64 -DMGO2WIN_STATIC_RUNTIME=ON`、`cmake --build build --config Release`、`ctest --test-dir build -C Release --output-on-failure` の順に実行します。

原本を必要とするテストは、その入力がある環境だけで有効になります。ソースには原本・復旧した実行用武器一覧・過去の素材変換器を含めていません。公開ソースだけの検証には模擬の一覧と画面データを使います。DPAPIを扱う2件のテストは、現在のWindowsユーザーの暗号化機能を利用できる環境が必要です。`Build-Title.cmd` は準備済みの進行表と素材が必要で、ゲーム原本からの一括変換機能ではありません。準備済みの動作確認にはReleaseのZIPを使用してください。

## ステージのデバッグとPCM BGM（2026-09-12）

F12でデバッグ表示を切り替えます。ルーム内のステージ情報でF5はローカル再初期化、F7/F8はBGM選択、F9は再生／停止、F6は環境音試聴です。サーバーのラウンドを強制変更する操作ではありません。n022aの18件の参考配置を表示し、車の既存配置点の間で車種を組み替えます。原版の出現条件・乱数・破壊挙動の再現ではありません。

BGMは `data/bgm` の標準16-bit PCM WAVをWindows XAudio2で再生します。ローカル原本52ファイルから79 WAV（約1.44 GB）を準備しました。元の識別名を残し、追加の音声バンクは `_layer1` などを付けています。4ch単位からステレオへの変換はネイティブ側の暫定ミックスで、元の場面切替やPS3ミキサーとの一致は未確認です。ループ位置は標準smplチャンクに保存しています。

`data/bgm/additional` にWAVを最大32曲置き、再起動してください。16-bit PCM、8～192 kHz、1～8ch、1曲256 MiB以下に対応。ファイル名が既定の表示名です（playlist1.txt／playlist2.txtで変更可能）。同じ内容の重複は除外します。追加曲IDはファイル全体のSHA-256で、一覧の並び順を通信上のIDにしません。

通常のリスポン時に変更を適用する選択処理と、強制曲がない場合のローカル選択曲→利用できる原曲→無音という処理を実装・単体検証しています。実対戦のリスポンイベントとスネークからの強制BGM通信はまだ未接続です。

## BGM表示名とリセット確認（2026-09-12）

同じ曲をリスポン時に再選択しても、再生中の音声を作り直さず再生位置を維持します。曲名の編集でも再生はリセットしません。別の曲を選んだときだけ曲を切り替えます（実リスポン通知への接続は引き続き未実装）。

曲名はUTF-8の `data/bgm/playlist1.txt`（原曲）と `data/bgm/additional/playlist2.txt`（追加曲）で編集できます。1行に `bgm_mgo_action01.wav=表示したい曲名` のように記入してください。日本語・ハングル等に対応し、表示名は最大128文字。空行と#から始まる行は無視します。ファイル名と表示名の区切りは=またはタブ。未指定・不正な表示名はファイル名に戻ります。編集後はF12を閉じて開き直すと再読込します。音声ファイルの追加・削除は再起動後に反映します。

F5は「ステージをリセットしますか？」のYES/NOを表示します。NOが初期選択。左右・Tabで選択しEnterで決定、またはボタンをクリックしてください。NO・Esc・F12でのデバッグ終了・フォーカス喪失は取消です。確認中にステージが変わった場合も取り消します。

## 待機と武器選択（2026-09-12）

入室後、F4で武器画面を開きます。左右・Tabでメイン／サブ／サポートを切替え、上下とEnterで選択し、F10で選択を保持します。Escで参加者一覧へ戻っても同じラウンドの選択は保持します。ステージは参加者一覧や武器画面を開いている間も読み込み、表示切替だけでは読み直しません。

現在の対象はn022a/TDMの通常キャラクター用の基本武器です。原データから価格と部屋の使用制限を復旧しました。DP ONでは価格を表示しますが、実際のDP残高をまだ受信できないため選択を確定できません。初期最低値1,000DPを受信済み残高として代用することはありません。特殊専用武器・追加アタッチメント・選択の送信・実出撃は未実装です。

MGO2HOSTは参加者が入ってから指定の待機時間を計測し、ルーム情報の受信確認後に準備段階へ進みます。これはステージ内の全物体の受信完了や戦闘開始ではありません。START／解除の通信、全員STARTによる早期開始、実ラウンド開始は引き続き開発中です。

## 専用ホストと共通設定（2026-09-12）

`MGO2HOST.exe` は既存の認証・ロビー通信を使い、TDM / n022aの専用ホスト部屋を公開します。既定UDPは5732。参加者16人に加えて専用ホスト1枠を使用し、ホストは出撃しません。アカウントは画面で入力し、任意の保存はWindowsユーザー単位のDPAPIで保護します。ソースにアカウントを埋め込んでいません。実行時はEXEの隣に準備済みの `data/network.gnk` と `data/lobbies.cfg` が必要です。

部屋作成前の「共通設定・武器制限」で、フォルダー形タブを切り替えます。人数・待機時間・戦績・FF・ロックオン・ネームタグ・チーム・ボイスチャット・キックなどの設定を、部屋作成と環境情報の送信へ反映します。適用した設定はこのアプリの起動中に保持され、取消・閉じるでは以前の設定を維持します。不正な値は該当項目で止めます。

武器制限は5分類52項目で、有効／無効、個別・分類単位の許可／禁止を操作できます。他分類や未解明ビットは保持します。LEVEL基準は22固定、クイック参加は現在利用できません。参照したサーバーが必要な設定値を保持しないためです。各設定の実対戦・音声・退出制御への効果、元の武器アイコン、特殊キャラクターを全員で自由に選択する機能は未完成です。UDP 5732での部屋公開成功は利用者から報告済みですが、今回追加した設定画面の検証はオフラインです。

`MGO2HOST.exe --smoke-options --report <出力先>` で、認証情報や通信素材を読まずに非表示の設定試験を実行できます。適用・取消・閉じる・不正値・送信値の一致を模擬設定で検証します。非表示のWindows入力欄は画像から文字が省略される場合があるため、実画面の目視確認とは区別してください。
