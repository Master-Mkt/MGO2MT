# MGO2MT Multi UI Designer

画面の部品と操作を編集するWindows用ツールです。ゲームと同じ `MGO2MTMultiUI.dll` で画像・文字・パネル・ボタン・プルダウンを描画します。「押す → 待つ → 音が鳴り終わる → イベント開始」を順番に設定できます。

## 起動

`MGO2MTMultiUIDesigner.exe` を起動します。同梱 `.runtime` を使う出力では.NETの追加インストールは不要です。EXE、DLL、`.runtime` フォルダーを含む出力一式を保持してください。これは既存公式.NET 10実行環境をローカル同梱する方式で、NuGet runtime packによるself-contained publishとは異なります。Windows x64用です。

`-FrameworkDependentOnly` で作成した小さい出力には.NET 10 Windows Desktop Runtimeが別途必要です。原ゲームの画像・動画・フォントはこのツールへ同梱しません。

## 操作

1. 左の「パネル」「テキスト」「画像」「ボタン」「プルダウン」を中央へドラッグします。
2. 中央で選択・移動します。四隅や辺のつまみでサイズを変えます。矢印キーは1 px、Shiftを押すと8 px。8 px吸着は上部で切り替えます。
3. 左の階層で要素を選び、「手前へ」「奥へ」で順序を変更できます。上ほど手前です。複製・削除もできます。
4. 右のプロパティで座標、サイズ、9アンカー、状態、フラグ条件、RGBA、不透明度、画像パス、文字列、フォントを編集します。文字のフォントはWindowsにインストールされたfamily名です。
5. 上部の画面、状態、ONフラグ、変数で表示条件を試します。必要フラグはすべてON、除外フラグは一つでもONなら非表示です。複数フラグはカンマで区切ります。
6. 「画像を取り込む」はPNG/JPEG/BMP/GIF/TIFF/ICO/DDSを **元の形式・内容のままコピー** し、素材フォルダーの `designer_textures` に置きます。元ファイルは変更しません。同名の異なる画像がある場合は別名を付け、上書きしません。
7. DDSが必要な場合だけ、隣の「DDS変換」を選びます。こちらは画像を非圧縮RGBA8 DDSへ変換して別ファイルを作ります。通常の取り込み・JSON書き出しでDDSへの変換は必要ありません。DDSはRGBA8/BC1/BC2/BC3に対応します。

GIFアニメーション、複数ページTIFF、複数画像ICOは **先頭画像を静止画として** 表示します。GIFのフレーム合成・再生、TIFFのページ選択、ICOの最大画像自動選択は行いません。透明部分はそのまま反映します。未指定の画像要素は編集枠のみ表示し、JSON書き出し前に画像指定を求めます。

Ctrl+Z: 元に戻す、Ctrl+Y: やり直す、Ctrl+D: 複製、Delete: 削除。配置やサイズ変更はドラッグ1回を1操作として戻せます。最大150操作を保持します。

## 保存とゲームでの確認

「保存」は `.mgoui` 編集用プロジェクトです。素材フォルダーの位置も記録するため、別PCへプロジェクトだけを移動した場合は「素材フォルダー」を指定し直してください。

「JSONを書き出す」はゲーム用 `MGO2MT.UI_LAYOUT.1` JSONと、そのJSON名の `.assets` フォルダーを出力します。参照画像と音声をSHA-256名でまとめ、相対パスへ置き換えます。PNG/JPEG/BMP/GIF/TIFF/ICO/DDSの拡張子と元バイト列を保持し、画像の再圧縮・DDSへの強制変換はしません。日本語や空白のあるフォルダーも使えます。素材不足時は以前のJSONを置き換えません。画像が変わった場合はJSONも再書き出ししてください。

ゲームで試す場合、書き出し先を `data/ui/layout.json` とし、`layout.assets` も隣に置きます。既存UIへ追加するレイヤーです。既存UIの置き換えではありません。ゲームはJSONの更新を約1秒ごとに確認します。JSONを削除、または形式が不正なら既存UIへ戻ります。例のJSONはデモ専用であり、ゲーム出力へ自動導入しません。

## ゲームから渡される画面・状態

|画面|状態|
|---|---|
|title|idle / loading / disconnected|
|menu|agreement / login / settings / characters / creation|
|lobby|groups / list / rooms / detail|
|briefing|waiting / loadout|
|hud|active / dead / reloading|
|result|summary|

状態 `*` は全状態です。任意の文字列も保存できますが、ゲームがその状態を渡さなければ表示されません。

フラグ: `loading`, `modal`, `respawn_waiting`, `alive`, `dead`, `aiming`, `reloading`, `first_person`, `auto_aim`。

テキスト変数: `hp`, `max_hp`, `ammo`, `reserve`, `weapon_id`, `remaining_ms`, `respawn_ms`。プロパティの「変数名」を設定し、上部の「変数…」から例 `hp=100` を入力するとプレビューできます。変数がない場合は固定テキストを使います。表示用変数はこのUI内に保存され、ゲームの体力や天候を直接変更しません。ゲーム操作へは対応するイベントを使用します。

## 座標

設計サイズは1280 × 720、表示は縦横比を維持して余白を付けます。x/yはアンカーからのオフセットです。

`左上 = (アンカーX × 1280, アンカーY × 720) + (x,y) − (アンカーX × 幅, アンカーY × 高さ)`

アンカーX/Yは0、0.5、1。例えば `center, x=0, y=0` は要素の中心が画面中央になります。編集時にアンカーを変えると、現在の見た目の位置を保って座標を計算し直します。

## ビルドと検証（開発者向け）

.NET SDK 10とWindowsDesktop targeting packが必要です。外部NuGetパッケージは使いません。

```powershell
.\Build.ps1 -NativeDll ..\build-mt\Release\MGO2MTMultiUI.dll
dotnet run --project Tests\MGO2MTMultiUIDesigner.Tests.csproj -c Release -- output\tests
output\MGO2MTMultiUIDesigner\MGO2MTMultiUIDesigner.exe --verify --capture output\capture
```

`--open project.mgoui`、`--asset-root フォルダー` も使用できます。`--capture` は実フォームと共通描画のPNGを保存して終了します。`--verify` は同時指定時にWinFormsの実マウスイベント経由で移動・サイズ変更、履歴、複製・削除、画像変換・書き出し再読込を検証します。`--image-fixtures ../tests/fixtures/multi_ui_images` も指定すると、透明PNG/GIF・複数画像TIFF/ICOと全9拡張子の元形式取り込み、入力不変、SHA一致、JSON書き出し後の表示を追加検証します。

現時点の範囲: 長方形のパネル/画像/テキスト/ボタン/プルダウン、9アンカー、重なり順、影、条件と文字変数、WAV/MP3再生、順序付き動作と待ち時間。新規グループ/部品そのものの回転編集/タイムラインアニメーション/フォントファイル同梱は未実装です。原LA2は下記の静止状態取り込みに対応します。原UIを完全再現したという主張はしません。

## 同梱サンプル

「開く」で `samples/example.mgoui` を選ぶと、画像入りサンプルを編集できます。素材フォルダーは `.`（プロジェクトと同じ場所）のため、出力フォルダーごと移動しても開けます。

- `samples/layout.example.json`: PNGとJPEGを元形式で参照するゲーム用JSON。
- `samples/textures/sample-swatch.dds`: このツール用に自作した3本の色帯。RGBA8 DDSで3段階の不透明度を含みます。
- `samples/textures/sample-swatch.png`: サンプルがそのまま参照する自作透過PNG。
- `samples/textures/sample-swatch.jpg`: サンプルがそのまま参照する自作JPEG。
- `samples/schemas/multi_ui_layout.schema.json`: ゲーム共通のJSONスキーマ。
- `samples/sample-provenance.json`: 生成方法と各ファイルのSHA-256。

原ゲームの画像は含みません。サンプルをゲームへ自動反映しません。

開発環境で再生成する場合:

```powershell
dotnet run --project SampleGenerator/GenerateSamples.csproj -c Release -- samples ../build-mt/Release/MGO2MTMultiUI.dll ../schemas/multi_ui_layout.schema.json
```

## 音・動作と待ち時間

1. ボタンを配置して文字を入力します。「画像を取り込む」で選択中のボタンの背景画像も設定できます。
2. 右の **Delay (ms)** は、押してから動作を始めるまでの待ち時間です。1000 ms が1秒。0ならすぐ開始します。
3. 下の **音・動作を設定…** を開き、「＋ 音を再生」からWAVまたはMP3を選びます。元の音声をそのまま素材フォルダーへコピーします。
4. 「音が最後まで鳴り終わってから次へ」をONにして、その下へ「＋ イベント開始」を追加します。上へ/下へで実行順を変更できます。「＋ 待つ」は動作と動作の間に入れる待ち時間です。
5. **動作を試す** をONにして中央のボタンをクリックします。押したまま外へ移動して離した場合は実行しません。履歴に「再生終了 → イベント開始」が並びます。
6. **停止・表示を戻す** で中止できます。編集、再読込、画面・状態の変更、ウィンドウからフォーカスが外れた場合も中止します。音声の読込失敗は、残りのイベントを開始しません。

音声は1ファイル64 MiB・10分以内。再生終了はMedia Foundationの実通知で判断します。チェックをOFFにすると再生開始後に次へ進みます。音声の同時重ね合わせやループは行いません。動作中の連打は追加予約されません。1つの操作につき32動作、レイアウト全体で8192動作、待ち時間1つにつき最大60秒です。

動作には「音を再生」「待つ」「イベント開始」「表示する値」「部品の表示」があります。「表示する値」は同じ変数名を設定した文字へ反映します。「部品の表示」は選択した部品を表示・非表示にします。

## ボタンとプルダウン

ボタン・プルダウンには、通常のRGBA背景色、カーソルが重なった色、押したときの色、文字色、背景画像を設定できます。「影を表示」、影の色・不透明度・位置も編集できます。背景画像は部品の幅・高さに合わせて表示します。

プルダウンを選択して下の **選択項目…** で、表示する名前・渡す値・最初の選択を設定します。項目は1〜64個です。「音・動作を設定」は選択が変わったときの動作です。選択値は「変数名」の表示用変数とイベントの値へ渡されます。Delayは選択変更後、動作開始前の待ち時間です。大量の項目は上下の矢印でページを切り替えます。

プレビューではTabで部品を選び、Enter/Spaceで押す・プルダウンを開く、上下キーで項目を選んでEnterで決定、Escapeで閉じる・中止ができます。部品を選択したときの「選択した部品を試す」は、プルダウンの場合はリストを開きます。

## ゲームへ渡すイベント

- `title.start`: タイトルの待機画面でスタートします。
- `menu.confirm`: メニュー・ロビー・ブリーフィング・結果画面で決定します。
- `menu.back`: 同じ画面で戻ります。

ゲームの読込中・確認ダイアログ表示中・フォーカスなしでは操作しません。その他の独自イベント名は実行履歴へ通知されます。独自のゲーム処理には、そのイベント名を処理するゲーム側の追加実装が必要です。JSONから任意のコードやURLを実行する機能はありません。プルダウンの天候サンプルは、選択値の通知を示す例で、HOSTの天候設定を変更するものではありません。

## 音・部品サンプルと検証

`samples/audio-controls.mgoui` を開くと、Delay 250 ms → 自作WAVの終了 → 120 ms → `title.start` のボタンと、MP3終了後に選択値を通知するプルダウンを試せます。WAV/MP3はこのツールの試験用に作成した短い音です。原ゲームの音声は含みません。

```powershell
MGO2MTMultiUIDesigner.exe --verify-audio 検証結果フォルダー
```

WAV/MP3を無音で実再生し、終了通知・ボタンクリック・プルダウン選択・待ち時間・取消・壊れた音の拒否・書き出し再読込を確認します。履歴と実フォームのPNGを保存して終了します。素材パスはフォルダー内の相対パスです。相対パス途中のリンク・ジャンクションは取り込み/書き出し時に拒否します。


## 原LA2を取り込む

「LA2取込」から元のLA2を選び、表示状態と保存先を指定します。推奨表示・初期状態・各イベントの終点を選択できます。必要な画像は近くの展開済みTXN/QAR/DLD/DLZから探し、不足した場合は素材フォルダーを指定します。MGO2MTEXCVなどで先に展開したリソースを使います。追加のPythonは必要ありません。

単色の四角形はパネル、原画像・回転・切り抜き・原字形はPNGの部品として、配置・色・透明度・重なりを反映します。保存先の素材フォルダーには元LA2と取り込みレポートも残します。元データは変更しません。取り込み後はボタンを重ねたり、画像部品へ音・動作を設定できます。

今回は静止した表示状態の取り込みです。原アニメーションの時間再生、GCX、動的文字列・変数は自動移植しません。加算合成は通常のアルファ合成で近似し、原タイトルの該当2部品をレポートに記載します。詳細と検証結果は同梱 `MULTI_UI_LA2_20260921.md` を参照してください。原タイトル・DRUM・ENVGを実デザイナーで取り込み、保存・書き出し後の描画一致を確認しています。

## 旧形式との互換

MGO2WIN.UI_LAYOUT.1 と MGO2WIN.UI_PROJECT.1 の既存ファイルも開けます。読み込み時は元ファイルを書き換えず、メモリ上で MGO2MT 形式へ移行します。保存・JSON書き出しは新しい MGO2MT 形式になります。レイアウト、素材の相対パス、音や動作の設定は保持します。
