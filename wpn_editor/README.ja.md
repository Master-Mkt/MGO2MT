# MGO2MT WPN Effect Editor

武器の数値、照準、発射・煙・爆発・出血、光、音を編集する Windows x64 用ツールです。`MGO2MTWpnEffectEditor.exe` を起動してください。同梱 `.runtime` を使うため .NET の追加インストールは不要です。EXEだけでなくフォルダー一式を保持してください。原ゲームの画像、音、モデル、設定データは同梱しません。

## はじめに

1. 「開く」でクライアントの `data/gameplay.json` を選びます。関連する `weapon_effects.json` があれば読み込み、無ければ編集時に新規作成します。`resources.weaponEffectsManifest` がある場合はその相対パスを優先します。
2. 左の一覧から武器を選びます。「基本」で威力・連射間隔・弾数・重量・移動/リロード倍率、「命中精度」でばらつき・構え別倍率・散弾数を設定します。各欄は入力範囲を検査します。
3. 「モデル」で原モデルのパスと原モーションIDを扱います。ゲーム側の既存武器挙動を越える新しいスクリプトやCPEF VMを生成するものではありません。
4. 「保存」でゲームと同じネイティブ検証を通します。不正な設定や不足素材があれば以前のファイルを保ちます。元ファイルは `.bak` に保持します。Ctrl+Z / Ctrl+Y で最大80操作を戻す・やり直すことができます。
5. 設定反映にはクライアント/HOSTを再起動してください。起動中のプロセスへ変更を注入しません。

各数値は元のJSON欄を保持して編集します。触っていない原データや将来の追加欄を勝手に削除しません。ただし現在のゲームが認識しない設定は、ゲームと同じ厳密検証により保存を拒否します。ゲームフォルダーの `assets.sha256` がある場合は、変更した設定と取り込んだ素材の行だけ更新します。配布時のリリースmanifest自体は変更しません。

旧MGO2WIN形式のJSONも読み込めます。読込時は元ファイルを変更せず、保存時にMGO2MT形式へ移行して元ファイルを `.bak` に保持します。

## 装備アイコン

「アイコン」タブで `visual.iconPath` を編集します。パスは `data` からの相対パスです。PNG・1024×512以内・4 MiB以内を使用できます。「パスを適用」またはEnterで変更し、透過部分は格子模様の上で確認できます。

「画像を取り込む」はPNG/JPEG/BMP/DDS/GIF/TIFF/ICOを読み込み、単一PNGに変換したコピーを `data/weapon_editor_assets/icons` に保存します。元の画像は変更しません。サイズの自動変更は行いません。「保存」でゲームの装備選択用アイコンへ反映されます。クライアントを再起動してください。変更・元に戻す・やり直すは他の武器設定と同様に扱えます。

パスが無ければ従来の `weapon-icons/index.tsv` を参照します。「原アイコンに戻す」はJSONの指定を削除します。画像が見つからない場合や範囲外のパスは保存を拒否し、以前の設定を保ちます。HOSTへは数値JSONだけをコピーするため、画像の配布はクライアント側で行ってください。ツール自体に原アイコンは同梱しません。

## 武器数値

発射間隔（ms）を正の値にすると原tick指定を解除します。原tickを正の値にするとms指定を解除します。リロード時間（ms）を変更すると原リロード時間指定とAK固有の原時間必須条件を解除します。原動作を保って速さだけ変える場合は「リロード速度倍率」を使ってください。

重量の移動影響は `移動速度倍率 ÷ (1 + 0.02 × kg)` という今回の native 計算です。原作から復元した重量公式という意味ではありません。薬室、散弾、構え別精度は対応する射線式の銃に使えます。ナイフ・投擲・設置爆薬・月光キックなどへの不適切な設定は保存時に拒否されます。原発射/リロードtickの単位を通常のmsとして読み替えないでください。

「命中精度」の値は µrad です。1,000 µrad = 1 mrad。「原設定に戻す」で個別精度指定を除去し、ゲームの既存動作に戻せます。薬室込みの総数は1000以内です。リロード後の弾数はゲームの薬室保持規則に従います。

## 粒子・光・照準

「粒子」で種類を選び、最大8層を編集します。「画像を取り込む」はPNG/JPEG/BMP/DDS/GIF/TIFF/ICOを原バイトのまま `data/weapon_editor_assets/textures` へコピーします。元ファイルを上書きしません。「原画像一覧」は手元のGWFXに収録された画像を表示します。「原素材テンプレート」は既に手元にある原画像を使う編集開始例です。テンプレートの粒子数・大きさ・時間が完全な原CPEF再現という意味ではありません。

アトラスの横・縦・使用コマ数・毎秒コマ数を指定できます。大きさと透明度は開始0～終了1の範囲で2～16点の直線補間曲線にできます。遅延、放出時間、1粒の寿命、速度、重力、回転、ランダム幅も設定できます。「光」は開始遅延・継続時間・範囲・色・明るさの曲線に対応します。「照準」は色、線幅、線長、中心点、最小間隔を扱います。ゲーム中に開閉する幅は武器の命中精度から計算されます。

「全武器の共通設定を編集」は粒子・光・音・照準の共通値を編集します。個別武器の設定があれば個別設定が優先されます。「元の設定へ」は該当する個別指定を除去し、共通値またはゲーム既存動作へ戻します。層をすべて削除した空配列は、その種類を明示的に無効にします。

中央の2Dプレビューはゲームと同じ粒子計算DLLを使い、寿命・軌道・回転・アトラス・曲線の時間経過を確認できます。スライダーで時刻を移動できます。描画は平面への参考投影です。加算合成、3D照明、深度、ソフトパーティクル、射撃時の照準の開閉は実ゲームで確認してください。タイムラインを手で動かすと音は停止します。

## 音

「音」タブで発射・リロード・弾切れ・薬莢・爆発を選びます。「WAVを取り込む」または「原音を設定」で、WAVか原音IDのどちらかを指定します。新規WAVは16bit PCM、モノラル/ステレオ、30秒以内、ループ情報なしに対応します。開始遅延と0～4倍の音量を指定でき、試聴にも反映します。4倍などで波形が上限を超えた部分はクリップします。

原音IDは `resources.audioManifest` の登録音を使います。「原音ID」タブの既存銃声/着弾音より、「音」タブの個別設定が優先されます。試聴とプレビュー再生は、他のウィンドウに切り替える・停止する・武器を変える・閉じると停止します。

## HOSTにも保存する

必要な場合だけ「HOSTのdata…」で保存先を指定し、「HOSTにもゲーム数値を保存」を有効にしてください。CLIENTとHOSTへ同一バイトの `gameplay.json` を保存し、各 `assets.sha256` の該当行を更新します。音・画像・エフェクトはクライアント用なのでHOSTへコピーしません。HOSTを停止してからの編集を推奨します。別の操作で開いているクライアントの設定が変更されていた場合、上書きせず再読み込みを求めます。

## 出力方式と依存

.NET 10の公式 Windows Desktop / Core Runtimeを `.runtime` としてローカル同梱し、AppRelativeで解決する方式です。NuGet runtime packによるself-contained publishとは区別します。外部NuGet依存はありません。`MGO2MTWpnEffects.dll` はゲームと同じ設定検証・粒子計算・画像復号を提供します。Windows標準の音声APIで試聴します。
