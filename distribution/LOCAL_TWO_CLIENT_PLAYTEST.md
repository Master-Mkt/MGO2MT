# Local two-client setup

See [the current full-set guide](docs/FULL_README.ja.txt). The client archive contains `START_KEYBOARD.cmd` and `START_PAD_1.cmd` for separate input roles. Run a matching-version HOST on the same LAN as configured by its operator. Use separate game accounts/characters as required by the service.

These launch helpers do not configure a router or firewall, create an account, start a remote HOST, or establish that two-PC combat has passed. Keep both client and HOST data with their corresponding executables and stop them before manual replacement.
